# 라벨링 기준 - S4 브랜드/논브랜드

> 원본: 이 파일. 옮겨 온 곳: [라벨링 기준 - S4 브랜드/논브랜드 (2026.11.12)](https://docs.google.com/document/d/1td2rgFSx30ayAQqbkGzGMcx6-sN2GBH8-LheGgTNp6I/edit) (2026-11-25 옮김)
> 기준을 바꾸면 이 파일을 고치고 [docs/decisions.md](../../docs/decisions.md)에 한 줄 남깁니다. 표본 기준은 [sampling/s4.yaml](sampling/s4.yaml)에 있습니다.

**결론: target 안에 특정 회사·브랜드·제품·서비스의 고유 이름이 하나라도 있으면 브랜드, 없으면 논브랜드입니다. 키워드의 의도어는 보지 않습니다.**

## 1. 목표와 범위

키워드의 target이 브랜드인지 판정합니다.

- 전제: S3에서 target·intent·site가 정확히 뽑혔다고 봅니다.
- 입력: keyword, target, SERP
- 출력: 브랜드 · 논브랜드
- 제외: target이 없는 키워드는 자동 논브랜드라 라벨링하지 않습니다.
- 언어: 한국어·일본어·영어

## 2. 공통 원칙

- **target만 봄**: 가격·후기·추천·뜻 같은 의도어(値段·口コミ·price·review·meaning)는 무시합니다.
- **하나라도 고유 이름이면 브랜드**: target 항목이 여럿이면 하나라도 브랜드일 때 브랜드. 예) 해커스, 토익 → 브랜드
- **작아도 브랜드**: 알려지지 않은 작은 브랜드·제품도 브랜드입니다.
- **시장 맥락으로 판단**: 같은 이름이 여러 뜻이면 시장 카테고리에서 가리키는 대상으로 판단. 예) 어학 앱 시장의 스피크 → 브랜드
- **판단 순서**: 키워드만 보고 알 수 없으면 1차로 SERP, 그래도 분명하지 않으면 2차로 직접 웹 검색. 낯선 이름은 꼭 확인합니다.
- **판단이 어려우면 보류**: 보류하고 이유를 남깁니다.

## 3. 라벨 기준표

| 라벨 | 정의 | 해당하는 이름 | 예시 |
|---|---|---|---|
| 브랜드 | 특정 회사·브랜드·제품·서비스의 고유 이름 | 회사·브랜드, 제품 라인·하위 브랜드·모델, 앱·온라인 서비스, 매장·체인·쇼핑몰, 영업 시설·업체(호텔·병원·클리닉·학원·와이너리), TV·웹 프로그램·잡지, 약칭·별칭·흔한 오기 | 아디 제로 evo sl, 올영, 카톡, らくらくスマートフォン, taylor made |
| 논브랜드 | 특정 회사의 상품이 아닌 일반 이름 | 카테고리어, 일반 명사, 성분·원료·소재, 품종·술 스타일, 일반 시술·서비스 종류, '브랜드'가 들어간 구, 장소로 쓰인 지명, 사람 이름, 시험·자격·제도, 공공기관·단체 | 로봇청소기, 칼슘, IPA, 하이볼, 사회복지사 2급, NISA |

## 4. 헷갈리기 쉬운 경계

- **시험·자격·제도**: 특정 회사의 상품이 아니라 논브랜드. 그걸 준비시키는 학원·회사·서비스가 브랜드. 예) 토익·사회복지사 2급·公認会計士·NISA·IRP → 논브랜드, 해커스 토익·에듀윌 공인중개사 → 브랜드
- **공공기관·단체**: 정부 기관·국제기구·학회는 논브랜드. 예) FAO, WHO, ISAPP
- **사람 이름**: 인물·유튜버·인플루언서 이름은 논브랜드. 본인 이름이 제품 브랜드명으로 쓰이면 브랜드.
- **아티스트·그룹**: 엔터테인먼트사·팬덤 앱 시장에서는 아티스트가 상품이라 브랜드, 다른 시장에서는 사람 이름이라 논브랜드. 예) 블랙핑크, BTS (엔터테인먼트사·팬덤 앱)
- **일반명처럼 쓰이는 상표**: 상표면 브랜드. 예) Chromebook, Tater Tots, Botox, Android
- **이름의 뜻**: target이 브랜드면 뜻을 묻는 키워드도 브랜드(샤넬 뜻, 스피크 뜻). 시장과 무관한 일반 단어의 뜻이면 논브랜드.
- **약칭·별칭·오기**: 특정 브랜드를 분명히 가리키면 브랜드. 예) 올영, 빅시, 카톡, zell(Zelle), rollie(Rolex)
- **작은 브랜드·낯선 카테고리**: 일반어나 제품 설명처럼 보여도 브랜드. SERP·웹 검색으로 특정 회사의 제품인지 확인. 예) 잘때꼭바르는크림(라벨영), Joint Food(Nordic Healthy Living)
- **지명**: 장소로 쓰이면 논브랜드. 지명과 이름이 같은 브랜드는 SERP가 브랜드를 분명히 보여 줄 때만 브랜드. 예) 丹波, 札幌
