# dataset/criteria - 라벨링 기준과 표본 기준

이 폴더가 기준의 **원본**입니다. Claude(라벨링 에이전트)와 사람 검수자가 모두 이 파일을 읽습니다.
Google Docs의 기준서는 공유용 사본이며, 크게 바뀌었을 때 이 파일에서 다시 맞춥니다.

| 파일 | 내용 |
|---|---|
| [s2.md](s2.md) · [s4.md](s4.md) · [s5.md](s5.md) | 라벨링 기준서: 목표, 판단 원칙, 기준표, 경계 사례, 통일 규칙 |
| [sampling/common.yaml](sampling/common.yaml) | 공통 표본 기준: 파티션 산업군, 칸당 건수, 사례 비율, 최종 라벨 규칙 |
| [sampling/s2.yaml](sampling/s2.yaml) · [s4.yaml](sampling/s4.yaml) · [s5.yaml](sampling/s5.yaml) | 태스크별 표본 기준: 라벨 몫, 쏠림 제한, 어려운 사례 유형, 제외 규칙 |

## 고치는 법

1. 검수 중 기준표에 없는 경우를 만나면 해당 기준서 끝의 **통일 규칙**에 날짜와 함께 한 줄 추가합니다.
2. 같은 커밋에서 [docs/decisions.md](../../docs/decisions.md)에 한 줄 남깁니다.
3. 기준이 바뀌면 그 기준에 걸리는 **이미 일치로 확정된 행**도 다시 점검합니다 (S5 구축에서 빠졌던 단계).
4. 통일 규칙이 자리를 잡으면 기준표·경계 장으로 옮깁니다.

태스크 사이 의존: S2는 여정 단계 판단을 S5 기준에 맡기고, S5는 S4 구분을 전제로 합니다. 한 기준서를 바꾸면 다른 기준서와 어긋나지 않는지 확인합니다.
